title: Nuxt 4 with static rendering (SSG)

**Context.** The portfolio is content that doesn't change per request and must rank in search engines.

**Decision.** Nuxt 4 with `ssr: true` + prerender (`nuxt generate`): real static HTML, no runtime server. Migrating to SSR/hybrid stays trivial if needed later.

**Consequences.** Top speed and SEO, zero compute cost; dynamic features (contact form, dynamic OG) will be added as targeted routes when needed.
